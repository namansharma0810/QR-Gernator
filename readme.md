# 🔳 QuickQR - QR Code Generator

A simple and user-friendly **QR Code Generator** built using **HTML, CSS, and JavaScript**.

Enter any text or information and generate a QR code instantly.

## ✨ Features

- 🔳 Generate QR codes from text
- ⚡ Generate QR code instantly with one click
- 🔄 Create a new QR code
- ⌨️ Simple text input
- 🎨 Clean and responsive interface
- 🚨 Displays an alert if no text is entered

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QR Server API
